## 🚀 Featured Engineering

### 🐄 Podago — *Dairy Farm Management System*
> A lightweight, highly accessible platform tailored for dairy cooperatives.
- **Architecture:** Offline-first design prioritizing local caching and seamless Firestore database synchronization.
- **Tech Stack:** Flutter, Firebase, Dart.
- **Impact:** Purely software and AI-model driven—zero reliance on complex IoT hardware, drastically reducing friction for rural adoption.

### 🌽 MkulimaSmart — *Agricultural Marketplace*
> Connecting farmers directly to markets with intelligent pricing models.
- **Architecture:** React Native frontend powered by Python-based backend analytics.
- **Tech Stack:** Linear Regression & Isolation Forest (Anomaly Detection).
- **Impact:** Smart pricing algorithms that analyze real-time market data to prevent exploitation and maximize farmer yields.

### 🏢 Locyfy — *Event Space Booking*
> A comprehensive web-based platform for booking event spaces and verified service providers.
- **Architecture:** Scalable web architecture focused on smooth user journeys.
- **Focus:** Streamlining logistics, scheduling, and provider verification to create a seamless booking ecosystem.
